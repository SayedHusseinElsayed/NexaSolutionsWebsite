# موقع Nexa Solutions

موقع الشركة الرسمي (عربي، من اليمين لليسار، يعمل على كل الأجهزة). موقع ثابت (HTML + CSS + JavaScript)، ومعاه دالة صغيرة واحدة (`functions/api/chat.js`) للمساعد الذكي على Cloudflare Pages.

## الصفحات

| الملف | الصفحة |
|---|---|
| `index.html` | الرئيسية: المنتجات، المنظومة، آخر التحديثات، الفيديوهات، العملاء، من نحن، الأسئلة، التواصل |
| `bexa.html` | Bexa POS (كان Nexa POS) — المميزات، الذكاء التحليلي، تطبيق المالك، الصور، الفيديوهات، الأسعار |
| `foodexa.html` | Foodexa (كان Nexa Rest) — المميزات، التطبيقات الثلاثة، الصور، الفيديوهات |
| `storexa.html` | Storexa (منصة المتاجر الإلكترونية) — المميزات، الربط مع Bexa، متاجر تجريبية، الأسعار |
| `videos.html` | مكتبة الفيديوهات مع تصفية حسب المنتج والنوع |
| `404.html` | صفحة غير موجودة |

كل صفحة منتج فيها: «كل المميزات» (كتالوج كامل بالبحث)، «التجربة المجانية»، و«شارك» (صورة جاهزة للمشاركة + روابط واتساب وفيسبوك).

## تعديل المحتوى بدون برمجة — `assets/js/data.js`

- **رقم الهاتف / واتساب / فيسبوك / الإيميل / العنوان**: أول الملف.
- **روابط المتاجر التجريبية** لـ Storexa: `storexaDemos` (حدّثها لما تطبيق المتاجر ينتقل لعنوانه الجديد).
- **الفيديوهات**: أضف عنصراً في `videos`. لو الفيديو على يوتيوب اكتب `youtube: 'ID'` (الجزء بعد `v=` في الرابط)، أو ارفع ملف mp4 في `assets/video/` واكتب `src`.
- **العملاء**: أضف عنصراً في `customers` (الاسم، المنتج، المدينة، الشعار، رأي العميل). القسم يعرض «انضم لعملاء Nexa» تلقائياً طالما القائمة فاضية. ضع الشعارات في `assets/img/customers/`.

- **كل المميزات لكل منتج**: `assets/js/features.js` (الوسوم: pro / full / new / soon).
- **النسخ التجريبية**: `trial` لكل منتج في `data.js` — غيّر الرابط ورقم الإصدار مع كل إصدار جديد.

نموذج التواصل في الرئيسية يفتح واتساب برسالة جاهزة فيها بيانات العميل — لا يحتاج سيرفر.

## المساعد الذكي (اسأل المساعد)

زر «اسأل المساعد» في كل الصفحات. بيجاوب الزوار من **قاعدة معرفة** مبنية من الموقع نفسه:
- `tools/build-knowledge.mjs` بيجمع نصوص الصفحات، الأسعار، كل المميزات، النسخ التجريبية، الفيديوهات، العملاء، وأي ملف `.md` في `knowledge/` ← `knowledge/kb.md` و`knowledge/kb.json`.
- **علّم المساعد معلومة جديدة**: اكتبها في `knowledge/notes.md` تحت عنوان `## ` واضح. الملف عام — ممنوع أي بيانات سرية.
- بعد أي تعديل في الموقع أو الملاحظات: `npm run build` (أو سيبها لـ Cloudflare — أمر البناء تحت).
- `functions/api/chat.js` بيبعت السؤال لـ Claude (`claude-opus-5-5`) مع قاعدة المعرفة، وبيرد بالعامية المصرية من المعلومات دي بس، ولو مش متأكد بيوجّه لواتساب.
- **من غير مفتاح API** (أو في المعاينة على الجهاز) المساعد بيشتغل برضه: بيدوّر في `kb.json` ويعرض أقرب إجابة من الموقع + زر واتساب.

التفعيل: Cloudflare Pages ← المشروع ← Settings ← Variables and Secrets ← أضف Secret باسم `ANTHROPIC_API_KEY` (من console.anthropic.com). يُفضّل تضيف Rate limiting rule على `/api/chat` من Cloudflare، وتحط حد شهري للصرف من لوحة Anthropic.

## صور المشاركة

`assets/img/share/<product>-poster.png` (1080×1350 للواتساب وفيسبوك) و`<product>-og.png` (1200×630، الصورة اللي بتظهر لما حد يبعت رابط الصفحة).
لإعادة توليدها بعد تغيير المميزات أو بيانات التجربة: عدّل النصوص في `tools/posters/make-posters.cjs` ثم `npm run posters` (يحتاج Microsoft Edge). كود الـ QR بيفتح صفحة المنتج على nexamasr.com.

## النشر على nexamasr.com

الموقع على **Cloudflare Pages** مربوط بـ GitHub (كل push على `main` بينشر تلقائياً):
1. Build command: `npm run build` — Build output directory: `dist` (البناء بيعمل قاعدة المعرفة وبينسخ ملفات الموقع العامة بس لـ `dist/`؛ مجلد `functions/` بيتاخد من جذر المشروع).
2. Variables and Secrets: `ANTHROPIC_API_KEY` (اختياري — من غيره المساعد بيرد من بيانات الموقع).
3. Custom domains: `nexamasr.com` و`www.nexamasr.com`.

### العناوين على nexamasr.com
| العنوان | إيه اللي عليه |
|---|---|
| `nexamasr.com` و`www` | موقع الشركة ده (Cloudflare Pages) |
| `storexa.nexamasr.com` | منصة Storexa: لوحات التجار والمالك وصفحاتها (Worker `nexa-e-commerce`، عن طريق المسار `*.nexamasr.com/*`) |
| `<اسم-المتجر>.nexamasr.com` | متاجر العملاء (نفس الـ Worker) |
| `lingering-sun-4a2c….workers.dev` | وركر التراخيص لـ Bexa وFoodexa وتطبيق المالك والويتر — مالوش علاقة بالدومين |

ملف `_redirects` بيحوّل عناوين Storexa القديمة على nexamasr.com (`/admin`، `/owner`، `/store`، `/media`، `/api/pos/*`، صفحات الأسعار…) لـ `storexa.nexamasr.com`، عشان اللينكات القديمة والصور المحفوظة ونسخ Bexa المتثبتة تفضل شغالة. و`sw.js` بيمسح الـ service worker القديم بتاع المتجر من أجهزة اللي زاروا الموقع قبل كده.

Cloudflare Pages يدعم الروابط بدون `.html` تلقائياً (`/bexa`، `/videos`) — وهي المستخدمة في `sitemap.xml` والروابط canonical.

## الصور والفيديوهات

- صور البرامج في `assets/img/<product>/` بصيغة WebP (مأخوذة من مجلدات marketing لكل منتج).
- الفيديوهات في `assets/video/` مضغوطة للويب (حوالي 27 ميجا إجمالاً). للشروحات الطويلة يُفضّل رفعها على يوتيوب وإضافتها بـ `youtube` بدل ملف.
- شعارات المنتجات في `assets/img/brand/`. شعار Nexa Solutions وشعار Storexa مصممان للموقع ويمكن استبدالهما بنفس الاسم.
